# Projeto de Interface no Figma

## 📌 Sobre o projeto

Este projeto consiste na criação de uma interface visual desenvolvida no **Figma**, com foco em organização, padronização e identidade visual.

O projeto apresenta um sistema de design definido para manter a aparência dos elementos consistente durante o desenvolvimento das telas. Foram estabelecidos padrões de cores, tipografia e tamanhos de texto para facilitar a aplicação do design.

## 🎨 Identidade visual

A identidade visual do projeto utiliza uma combinação de tons de **azul, laranja, preto, branco e verde**, criando uma aparência moderna e organizada.

A paleta principal conta com:

* Azul primário: `#539AE9`
* Azul secundário: `#267FE3`
* Azul escuro: `#1866BE`
* Laranja primário: `#FF6200`
* Laranja secundário: `#FF8133`
* Preto: `#0B0A0A`
* Branco: `#FFFFFF`
* Cinza claro: `#F2F5F7`
* Verde de sucesso: `#52D65F`
* Vermelho de alerta: `#D11C00`

## 🔤 Tipografia

A fonte escolhida para o projeto foi a **Poppins**, utilizada como padrão tipográfico da interface.

A escala de fontes definida no projeto é:

| Elemento  | Tamanho |
| --------- | ------: |
| Small     |    14px |
| Parágrafo |    16px |
| H5        |    18px |
| H4        |    24px |
| H3        |    28px |
| H2        |    34px |
| H1        |    40px |

Essa padronização permite manter uma hierarquia visual clara entre títulos, subtítulos e textos.

## 🖥️ Ferramenta utilizada

**Figma**

O Figma foi utilizado para criação e organização dos elementos visuais, permitindo estruturar a identidade do projeto e definir os padrões que serão utilizados posteriormente no desenvolvimento da interface.

## 🎯 Objetivos

O projeto tem como objetivos:

* Criar uma identidade visual consistente;
* Definir uma paleta de cores para a interface;
* Padronizar a tipografia;
* Estabelecer uma hierarquia visual para os textos;
* Facilitar a implementação do design durante o desenvolvimento;
* Criar uma base visual organizada para as futuras telas do projeto.

## 📁 Estrutura do projeto

O projeto de design é organizado principalmente em:

**Logo:** elemento utilizado para representar visualmente o projeto.

**Cores:** conjunto de cores primárias, secundárias e cores destinadas a estados como sucesso e perigo.

**Tipografia:** utilização da família Poppins como padrão.

**Font Scale:** definição dos tamanhos de textos, indo de 14px até 40px.

## 🚀 Próximos passos

A partir deste projeto desenvolvido no Figma, os próximos passos podem incluir a criação das telas completas da aplicação, desenvolvimento da interface utilizando HTML, CSS e JavaScript e implementação das funcionalidades previstas para o projeto.
